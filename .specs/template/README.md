# Template Project

This folder describes the reusable template as a maintained product.

Root `README.md` and root `AGENTS.md` are Template Project files in this repository. They are intentionally replaced by `.specs/generated/README.md` and `.specs/generated/AGENTS.md` when a new project is created from the template.

## Responsibilities

- Keep the Dioxus 0.7 workspace generic and reusable.
- Keep template-maintenance docs, rules, and specs separate from generated-project starter content.
- Keep `.specs/generated/` ready to become the root docs and starter specs of a new repo.
- Update `.codex/project-identity.md` and `.codex/skills/create-project-from-template/` when the copy/rename workflow changes.

## Specs

Template Project specs live under `.specs/template/specs/`. Generated Project starter specs live under `.specs/generated/specs/`.
